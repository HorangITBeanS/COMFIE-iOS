# Memo Input Manual Validation

## 목적
- Draft SoT 일원화 이후, 실제 사용자 시나리오에서 다음 두 가지가 깨지지 않는지 확인한다.
- ComfieZone(원문 모드) 편집 시 기존 이모지 매핑 유지
- 한글 입력(IME 조합/커서 이동) 중 입력 안정성 유지

## 사전 조건
- iOS Simulator에서 최신 빌드 실행
- 기존 메모가 없다면 먼저 샘플 메모 1개를 만든다
- 위치를 ComfieZone로 토글할 수 있는 상태를 준비한다

## 시나리오 1: ComfieZone에서 매핑 유지
1. 기본(이모지 모드)에서 `"가나"`를 입력해 메모를 저장한다.
2. ComfieZone(원문 모드)로 진입한다.
3. 방금 저장한 메모를 수정 모드로 연다.
4. 원문 끝에 `"다"` 1글자를 추가한다.
5. 저장 버튼(체크)을 눌러 수정 저장한다.
6. 다시 이모지 모드로 돌아와 같은 메모를 확인한다.

### 기대 결과
- 기존 `"가"`, `"나"` 위치의 이모지 매핑은 수정 전과 동일하다.
- 새로 추가한 `"다"` 위치만 새 매핑이 반영된다.
- 저장 중 커서 점프/텍스트 초기화/크래시가 없다.

## 시나리오 2: 한글 입력 + 커서 이동 안정성
1. 메모 입력창에 포커스를 둔다.
2. `"가나다"`를 입력한다.
3. 커서를 문자열 중간으로 이동한다(탭 또는 길게 눌러 이동).
4. 중간 위치에 `"라"`를 추가 입력한다.
5. 입력 중 배경 탭/다시 포커스를 반복한다.
6. 최종 저장 버튼을 눌러 메모를 저장한다.

### 기대 결과
- 입력 중 조합이 깨지거나 텍스트가 강제로 리셋되지 않는다.
- 커서 이동 후에도 이어서 입력이 정상 동작한다.
- 저장 후 원문이 의도한 문자열과 일치한다.

## 기록 항목
- 테스트 일시
- 빌드/브랜치 정보
- 각 시나리오 Pass/Fail
- Fail 시 재현 단계와 화면 캡처/영상
